A. Profile Saya

Halo! Nama saya Arzarizqi Prihardika L . Saya adalah mahasiswa aktif Program Studi Sistem Informasi di Fakultas Ilmu Komputer. Saya memiliki ketertarikan yang besar dalam bidang pengembangan aplikasi web, perancangan basis data, serta analisis sistem informasi. Saya senang mempelajari teknologi baru yang dapat membantu menyelesaikan berbagai permasalahan di bidang teknologi informasi. Selain itu, saya juga tertarik untuk mengembangkan kemampuan dalam pemrograman dan pembuatan sistem yang mudah digunakan. Selama menjadi mahasiswa, saya terus berusaha meningkatkan pengetahuan dan keterampilan melalui berbagai tugas dan proyek perkuliahan.

Halaman web ini dibuat menggunakan HTML5 murni tanpa menggunakan CSS untuk memenuhi instruksi pembuatan struktur dasar web. Dalam pembuatan halaman ini, saya menggunakan berbagai tag HTML untuk menyusun struktur dan menampilkan informasi. Saya juga mempelajari fungsi dari setiap tag agar dapat digunakan sesuai dengan kebutuhan halaman web. Pembuatan halaman ini menjadi salah satu latihan untuk memahami dasar-dasar pengembangan web. Dengan latihan ini, saya berharap dapat memahami HTML dengan lebih baik dan mampu menggunakannya dalam membuat halaman web yang lebih kompleks.
